# 🧩 LEGO Puzzle — Повна документація проєкту

Ласкаво просимо до технічної документації мобільної 3D-головоломки **LEGO Puzzle**.  
Усі власні C# скрипти проєкту організовано за трирівневою архітектурою:

```
Assets/Scripts/
├── LevelSystem/
│   ├── Data/       ───> Контейнери даних (ScriptableObject, моделі деталей, сітка)
│   ├── Runtime/    ───> Ігровий процес, фізика, бустери, економіка, UI, Juice
│   └── Editor/     ───> Генератор рівнів, BFS-солвер, візуальні редактори
└── MenuButtonController.cs ───> Навігація в головному меню
```

---

## 🏗️ Архітектура та Життєвий Цикл

### 1. Потік сцен (Scene Flow)
1. **[`Menu.unity`](file:///c:/FORK/LEGO/Assets/Scenes/Menu.unity)**:
   * Гравець запускає гру, бачить баланс монет, гемів та серця.
   * Може крутити слот-машину («Лото») або зайти в магазин бустерів.
   * При натисканні «Грати» [`MenuButtonController`](./Runtime/README.md#menubuttoncontrollercs) перевіряє `HeartManager.HasHearts()`. Якщо життя є — завантажує ігрову сцену.
2. **[`Game.unity`](file:///c:/FORK/LEGO/Assets/Scenes/Game.unity)**:
   * [`LevelLoader`](./Runtime/README.md#levelloadercs) зчитує збережений індекс рівня з `PlayerPrefs` (`LEGO_CurrentLevelIndex`).
   * Завантажує відповідний асет [`LevelData`](./Data/README.md#1-leveldatacs) зі списку `allLevels`.
   * Спавнить 3D-клітинки сітки та деталі LEGO.
   * Адаптивно налаштовує зум і позицію камери під реальний розмір рівня.
   * Гравець пересуває деталі; при виведенні блоку в ворота свого кольору деталь покидає поле.
   * При виході всіх обов'язкових деталей: зараховується перемога, нараховується +1 гем і монети, відкривається `WinPanel`.
   * Кнопка «Далі» одразу завантажує наступний рівень (`LoadNextLevel()`).

## 🛠️ Швидкий старт для розробника

### Як згенерувати новий рівень?
1. У верхньому меню Unity відкрийте: **`Tools` ➔ `LEGO Level Generator` ➔ `Відкрити вікно генератора`**.
2. Оберіть вкладку **Single Level Studio**, вкажіть складність або налаштуйте розмір сітки вручну.
3. Натисніть **«🎲 Згенерувати рівень»**. Бот автоматично перевірить прохідність і покаже мінімальну кількість ходів.
4. Натисніть **«💾 Зберегти рівень»** — він збережеться в папку `Assets/Levels/Level_XXX.asset`.

### Як згенерувати серію рівнів пачкою?
1. У тому ж вікні оберіть вкладку **Batch Generator**.
2. Вкажіть діапазон (наприклад, з 1 по 20 рівень).
3. Оберіть режим **«Плавне зростання складності за номерами»**.
4. Натисніть **«🚀 Запустити пакетну генерацію»**. Генератор автоматично створить усі рівні та прив'яже їх до сцени `Game.unity`.

### Як намалювати рівень власноруч?
1. Відкрийте **`Tools` ➔ `LEGO Level Editor`**.
2. Оберіть розмір сітки, розставте ворота потрібних кольорів та розмістіть блоки на полі.
3. Натисніть **«Save to Asset»**.
